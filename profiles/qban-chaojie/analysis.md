# 评估目标

评估一条信息是否适合作为小红书「商业图解笔记 / 每天一个省钱真相」的 6 页 Q 版图解图文素材，能否在视觉上拆穿商家的算盘，并给普通消费者可直接操作的避坑指引。

# 评分标准

- **9–10：爆款图解主选题。** 极具反直觉商业算盘、直击家庭高频支出痛点（如买菜/点外卖/买日化），有权威事实或行业内部揭秘支撑，小夫妻手绘冲突感极强。
- **7–8：优质图文素材。** 算盘清晰、对比鲜明，能提炼出 1 个非常明确的省钱/防坑小动作。
- **5–6：合集备选素材。** 细节较单一，适合并入《商超 5 大套路》等盘点型合集。
- **3–4：偏软或偏泛。** 商业套路不够生活化，或距离普通家庭柴米油盐太远。
- **0–2：噪音。** 宏观股市行情、纯理论无对策、广告推销。

# 评估要求

优先筛选有数字对比、有账本账面、有具体商品场景的内容。
