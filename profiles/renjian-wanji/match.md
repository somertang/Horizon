# 人间晚记·选稿匹配标准

当一条内容能够为「30+ 都市职场人、程序员与白领群体」提供真实境遇反思、深度认知增量、第二曲线破局启发或社会情绪洞察时，使用此配置。

### 重点关注与保留：
1. **职场现实与中年境遇**：30+ 年龄瓶颈、大厂与外企职场真实生态、裁员与薪酬趋势、职场内耗与边界感建立、体面退出与心态调适；
2. **第二曲线与被动收入探索**：程序员与白领的技术出海、独立开发、自媒体创业、咨询与轻资产商业实操、反内卷生活实践；
3. **AI 对白领的真实冲击**：不是抽象炫技，而是 AI 真正对具体岗位（开发、运营、设计、分析）的工作方式、薪资与生存空间带来的实质性改变；
4. **高质量社会情绪与生活观察**：都市人的情感自处、家庭与个人边界、中年清醒叙事、非虚构深度报道。

### 坚决剔除与过滤：
- 纯代码语法、常规开源小版本更新、纯技术参数跑分；
- 廉价鸡汤、情绪煽动、毫无事实支撑的焦虑贩卖；
- 泛娱乐明星八卦、纯宏观泛泛而谈的政策通稿。
