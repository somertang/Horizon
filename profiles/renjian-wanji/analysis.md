# 评估目标

评估一条信息是否值得作为「人间晚记」公众号的深度选题素材，能否在 24–72 小时内提炼为一篇具有穿透力、温和理性且能引发 30+ 读者强烈共鸣的深度文章。

# 评分标准

- **9–10：绝佳主选题。** 具有极强的社会典型性或深刻的认知颠覆，切中 30+ 职场人核心痛点（如中年危机破局、职业安全感重塑），有翔实数据或真实个案支持，可直接展开为一篇高传播度长文。
- **7–8：优质选题/深度案例。** 事实清楚、角度新颖，能够作为核心论据或独立中篇短文，提供明确的认知增量。
- **5–6：背景素材。** 具有一定启发性，但叙事单一或深度不足，适合作为某篇长文的佐证案例或段落引用。
- **3–4：低相关。** 过于偏向通用行业资讯，缺乏对普通个体的温度与痛点穿透。
- **0–2：噪音。** 煽动性情绪宣泄、广告软文、纯技术代码或无关八卦。

# 评估要求

重点观察材料中的“真实冲突”与“人味”，识别故事背后的体制、经济与心理机制。
